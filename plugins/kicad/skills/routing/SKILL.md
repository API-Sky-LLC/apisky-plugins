# Routing

Порядок важнее аккуратности: сначала то, что нельзя двигать.

1. **Размещение**: разъёмы по краям, силовая часть отдельно от аналоговой, кристалл рядом
   с ножками МК, развязка вплотную к пину питания.
2. **Сила**: ширина дорожки от тока (≈1 A на 0.5 мм меди 35 мкм при допустимом нагреве),
   переходные отверстия дублируй, полигон земли — первым слоем.
3. **Дифференциалы**: одинаковая длина в паре, одинаковый зазор по всей длине, минимум
   переходных отверстий, не разводи пару по разным слоям без возвратного пути.
4. **Высокоскоростные шины**: длина в группе в пределах допуска из даташита, ссылка на
   землю непрерывна под дорожкой.
5. **Остальное**: сигнальные дорожки последними, углы 45°, минимум слоёв.

Каждый слой заканчивается полигоном земли. Если полигон «порезан» дорожками — это баг
разводки, а не косметика: вернись к размещению.
